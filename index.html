Three tools for thinking clearly, explained for people meeting them for the first time.

Each guide teaches one tool from the beginning. You don’t need any background. Every new word is explained when it first appears, and each guide uses its own small made-up example.

1 · Start here

Which guide do you need?

Analysis can sound grand. In practice it means looking at a situation carefully before you act. These three tools are the most useful starting points, and each one fits a different moment.

Three questions, three guides

If you aren’t sure which question you have, start with the first one. Drawing a map of what you know usually shows you which of the other two you need.

  • Mind MappingGet a whole topic onto one page, and see what you know and what is missing.Open the guide
  • Root Cause AnalysisFind out why something went wrong, so you can stop it happening again.Open the guide
  • SWOT AnalysisSort what you know into strengths, weaknesses, opportunities and threats, and decide.Open the guide
2 · Choosing

Pick by the question you have

Most real problems are not one tool’s job. Look at what you are trying to find out right now.

Pick by the question
If your question is…Use thisYou get
“There’s a lot going on and I don’t know where to start.”Mind MappingAll the parts on one page, grouped, with gaps showing.
“Something went wrong and I need to know why.”Root Cause AnalysisA tested cause, and fixes that deal with it.
“We have an option. Is it a good idea?”SWOT AnalysisThe inside and outside factors side by side, and a first step.
“I need to explain a decision to other people.”SWOT AnalysisA clear record of what you weighed and why.

Some questions need none of these. If you only need a number, look it up. If you need to build something new, talk to the people who will use it. Each guide says early on when another tool fits better.

3 · Working together

How the three guides fit together

The guides stand alone, but they also pass the baton. A common order is to look around first, then find out why, then weigh your options, and finally act and check.

One possible order

You can enter at any point and leave at any point. Real work loops back, so expect to return to an earlier station.

Map, then investigate

A mind map can list the possible causes of a problem. Root cause analysis then tests each one against evidence.

Investigate, then weigh up

Once you know the cause, there may be several ways to fix it. A SWOT can help you compare them.

Weigh up, then map the plan

When you choose an option, a map of its branches shows what has to happen, and who will do each part.

4 · Shared habits

Four habits that run through all three guides

The tools are different, but good analysis has a few things in common. You will see these again and again.

1Say it in plain words

If a word is new, it is explained where it first appears. If a sentence is hard to follow, shorten it.

2Lean on evidence

Evidence means facts you can check. Opinions are useful clues, but they are not findings.

3Look at the process, not the person

When something goes wrong, ask what made it easy to happen. Blame stops people telling you what really occurred.

4Start small

Try a small first step, then check whether it worked. A pilot is cheaper to undo than a launch.

Tip
If you remember only one thing: write down how you would check each claim. If you can’t, mark it as an opinion.
5 · Using the guides

How each guide is laid out

All three guides follow the same plan, so once you have read one, the others will feel familiar.

The plan, in order
  1. In short. Three points that give you the whole idea in half a minute.
  2. An everyday picture. The tool shown on something you already know, before any method.
  3. When to use it. And when another tool fits better.
  4. The steps. A plain method, with a picture.
  5. How to tell it is done well. Checks you can apply to your own work.
  6. An example. Each guide has its own small, made-up case, introduced only after the basics. The examples are invented, so don’t read them as real events.
  7. The tools. Each one with what it is for, how to do it, an example picture, and what to watch out for.
  8. Common problems, going further, a checklist, and sources.
